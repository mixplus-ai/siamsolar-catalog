# ย้าย Solar Catalog ไป Netlify

หลักการ: หน้าเว็บ (index.html) อยู่บน Netlify ส่วน Google Sheet และ Google Drive ยังเป็นที่เก็บข้อมูลเหมือนเดิม โดย Apps Script ทำหน้าที่เป็น API ให้หน้าเว็บเรียกผ่าน `fetch` แทน `google.script.run`

ไฟล์ในชุดนี้

| ไฟล์ | ใช้ที่ไหน |
|---|---|
| `apps-script/Code.gs` | วางทับใน Apps Script เดิม (ไม่ได้ใช้บน Netlify) |
| `index.html` | อัปโหลดขึ้น Netlify |
| `netlify.toml` | อัปโหลดขึ้น Netlify คู่กับ index.html (ทำให้ `/admin` ใช้งานได้) |

## ขั้นที่ 1: อัปเดต Apps Script

1. เปิดโปรเจกต์ Apps Script เดิม แล้ววางโค้ดจาก `Code.gs` ทับทั้งหมด
   (ไฟล์ `Index.html` เดิมใน Apps Script เก็บไว้ได้ ลิงก์ /exec เก่าจะยังเปิดหน้าเดิมได้)
2. ตั้งรหัสผ่านแอดมิน (**จำเป็น** ถ้าไม่ตั้งจะล็อกอินไม่ได้): ไปที่ ⚙️ Project Settings > Script Properties > Add script property
   - `ADMIN_USER` = ชื่อผู้ใช้
   - `ADMIN_PASS` = รหัสผ่านใหม่ (อย่าใช้ solar1234 เพราะรหัสนี้เคยถูกแชร์ไปแล้ว)
3. เลือกฟังก์ชัน `setupPermissions` แล้วกด Run หนึ่งครั้ง เพื่ออนุญาตสิทธิ์
4. กด **Deploy > Manage deployments** > เลือก deployment เดิม > ✏️ Edit > Version: **New version** > Deploy
   - Execute as: **Me**
   - Who has access: **Anyone** (ต้องเป็น Anyone ไม่ใช่ "Anyone with Google account" ไม่งั้น Netlify เรียกไม่ได้)
   - ถ้าแก้ deployment เดิม URL /exec จะเหมือนเดิม ถ้ากด New deployment จะได้ URL ใหม่ ต้องเอาไปใส่ใน index.html
5. ทดสอบ: เปิด `<URL /exec>?action=products` ในเบราว์เซอร์ ต้องเห็นข้อมูลเป็น JSON

## ขั้นที่ 2: ตั้งค่า index.html

เปิด `index.html` แล้วแก้ส่วน `CONFIG` ด้านบน

```js
API_URL: 'https://script.google.com/macros/s/.../exec',  // ใส่ URL /exec ของคุณ (ใส่ของเดิมไว้ให้แล้ว)
LINE_ID: '@siamsolar',   // LINE OA ใส่ @ นำหน้า ระบบจะพิมพ์ชื่อสินค้าให้อัตโนมัติ
PHONE: '0812345678',
FACEBOOK_URL: 'https://m.me/ชื่อเพจ',
EMAIL: 'sales@...'
```

ช่องไหนเว้นว่าง ปุ่มนั้นจะไม่แสดง ถ้าเว้นว่างทั้งหมด แถบติดต่อเซลล์จะซ่อนไป

## ขั้นที่ 3: ขึ้น Netlify

**วิธีง่ายสุด (ลากวาง)**
1. ใส่ `index.html` และ `netlify.toml` ไว้ในโฟลเดอร์เดียวกัน
2. ไปที่ https://app.netlify.com/drop แล้วลากทั้งโฟลเดอร์ไปวาง
3. ได้ลิงก์ `https://xxxx.netlify.app` เปลี่ยนชื่อได้ที่ Site configuration > Change site name

**วิธีผ่าน GitHub (แก้ไฟล์แล้วเว็บอัปเดตเอง)**
1. สร้าง repo ใหม่ ใส่ไฟล์ทั้งหมดในชุดนี้ (`Code.gs` อยู่ในโฟลเดอร์ `apps-script/` ไว้เป็นสำเนาเท่านั้น ต้องไปวางใน Apps Script เองตามขั้นที่ 1)
2. Netlify > Add new site > Import an existing project > เลือก repo > Deploy (ไม่ต้องตั้ง build command)

## ฟีเจอร์แชร์และส่งสเปคเข้า LINE

- ทุกสินค้ามีลิงก์ของตัวเอง เช่น `https://ชื่อเว็บ.netlify.app/?p=PROD-123` เปิดแล้วเข้าหน้าสินค้านั้นทันที
- ในหน้ารายละเอียดสินค้ามีปุ่ม **ส่งสเปคเข้า LINE** (ส่งชื่อ แบรนด์ สเปค ลิงก์ Datasheet และลิงก์สินค้า), **ส่งลิงก์เข้า LINE**, **คัดลอกลิงก์**, **คัดลอกสเปค** และ **แชร์อื่นๆ** (เมนูแชร์ของมือถือ)
- บนการ์ดสินค้ามีปุ่ม LINE เล็กๆ สำหรับส่งสเปคได้เลยโดยไม่ต้องเปิดหน้ารายละเอียด
- **เคล็ดลับ:** พิมพ์สเปคในช่องรายละเอียดแบบ `หัวข้อ: ค่า` บรรทัดละ 1 รายการ (เช่น `กำลังไฟ: 5 kW`) หน้าเว็บจะแสดงเป็นตารางสเปค และข้อความที่ส่งเข้า LINE จะเป็นรายการอ่านง่าย
- แก้ชื่อร้าน ข้อความหัวเว็บ และรายชื่อแบรนด์/สีแบรนด์ ได้ที่ `CONFIG` และ `BRANDS` ด้านบนของ index.html

## การใช้งาน

- หน้าลูกค้า: `https://ชื่อเว็บ.netlify.app`
- หน้าแอดมิน: `https://ชื่อเว็บ.netlify.app/admin`
- เวลาแก้สินค้าใน Sheet หรือผ่านหน้าแอดมิน หน้าเว็บจะเห็นทันทีโดยไม่ต้อง deploy Netlify ใหม่
- ต้อง deploy Netlify ใหม่เฉพาะตอนแก้ `index.html` (เช่น เพิ่มแบรนด์ เปลี่ยนเบอร์โทร)
- ถ้าแก้ `Code.gs` ต้องทำขั้นที่ 1 ข้อ 4 (New version) ทุกครั้ง

## สิ่งที่เปลี่ยนจากของเดิม

- **ความปลอดภัยของหลังบ้าน:** ของเดิมตรวจรหัสผ่านแค่ตอนเปิดหน้า Dashboard แต่ฟังก์ชัน `getAllProducts`, `saveProduct`, `uploadFileToDrive` ถูกเรียกตรงได้โดยไม่ต้องล็อกอิน ตอนนี้ล็อกอินแล้วจะได้ token (อายุ 6 ชั่วโมง) และทุกคำสั่งแก้ไขต้องมี token ที่เซิร์ฟเวอร์ตรวจ
- รหัสผ่านย้ายไปเก็บใน Script Properties ได้ ไม่ต้องเขียนไว้ในโค้ด
- รูปจาก Google Drive แสดงใน `<img>` ได้แล้ว (ของเดิม `file.getUrl()` เป็นลิงก์หน้า Drive ซึ่งใส่ในรูปไม่ขึ้น) ลิงก์ Drive เก่าใน Sheet ก็แปลงให้อัตโนมัติ
- กันข้อความใน Sheet ที่มีเครื่องหมาย `'` หรือ `<` ทำหน้าเว็บพัง
- ช่องค้นหาแสดงบนมือถือด้วย และค้นในรายละเอียดสินค้าได้
- เพิ่มปุ่มติดต่อเซลล์ (แถบล่างจอ และในหน้ารายละเอียดสินค้า)
- ตอนแก้ไขสินค้า คอลัมน์อื่นใน Sheet ที่ฟอร์มไม่มี จะไม่ถูกล้างเป็นค่าว่าง
- รูป placeholder เดิม (via.placeholder.com) ปิดบริการแล้ว เปลี่ยนเป็นรูปในไฟล์แทน

## ข้อจำกัดที่ควรรู้

- ไฟล์อัปโหลดควรไม่เกินประมาณ 20MB ต่อไฟล์ (ข้อจำกัดของ Apps Script)
- ครั้งแรกที่เปิดหน้าเว็บอาจช้า 1 ถึง 3 วินาที เพราะ Apps Script ต้องตื่นก่อน
